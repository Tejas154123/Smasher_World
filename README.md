# Smasher_World
Enter the world of Smasher and get to know more about him, his interests, and the projects he has worked on.

## About The Project
Smasher World is a personal portfolio-style website that introduces me, my interests, and some of the projects I have made so far. It includes both robotics-based and AI-based projects along with some real-life photos and a photo of my robot.
The initial design of this project was created using Figma. I then converted the design into a working website using HTML and CSS.

## Design
The website was initially designed in Figma before being developed.
I experimented with different colors, borders, and a retro grid background to create the final look.
The photos used in the website are from my own projects and real life.

## Development
The core languages used in this project are:

- **HTML** – Used to create the structure and content of the website.
- **CSS** – Used for the complete styling, layout, responsive design, and animations.

The animation and some parts of the implementation were developed with the help of AI tools. The overall concept, content, project selection, and design direction were created by me.
